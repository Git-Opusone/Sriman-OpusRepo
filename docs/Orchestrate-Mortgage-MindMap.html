Platform Overview — Mind Map
Full end-to-end architecture of Orchestrate-Mortgage showing all major components and their relationships
Core Design Principle: "One Agent → Many Agents" — a single AI agent that learned to search one county was scaled to discover and map all 3,200+ counties across 50 US states. V3.0 adds Texas Tax Office Dual-Search: 254 TX counties, 9 Tax Office handlers, and sequential CAD→Tax Office search. Deterministic handlers ($0 cost) cover 15+ platforms; GPT-4o-mini AI fallback covers edge cases. CAPTCHA resolution is tiered: Tier-1 free (Cloudflare auto-pass) → Tier-2 CapSolver paid (last resort only).

CAPTCHA & Access Control Scenarios Handled

County assessor URLs are access-controlled by many different barrier scenarios that must be navigated programmatically:

8.1 Country IP Validation

Many counties restrict access to US IP addresses only. US-region deployment eliminates IP-block retries.

8.2 Cloudflare Bot Detection

Human/Bot detection via Cloudflare Turnstile. Bypassed using Playwright Stealth plugin (spoof WebGL, navigator.webdriver).

8.3 CAPTCHA Types

reCAPTCHA v2/v3, hCaptcha, and custom CAPTCHA implementations. Detected with detectCaptcha() — returns captchaBlocked result.

8.4 Concurrency CAP

NetronOnline and county sites throttle concurrent sessions. MAX_CONCURRENT = 5 browser processes managed by server.js.

8.5 Search Timings

Per-search timeout: 180s (3 min). Angular SPA timing, frameset delays, ASP.NET postback waits all handled per platform.

8.6 SSL & Session

Self-signed certificate support. Tyler sIndex session handling. Disclaimer/Terms modal dismissal before search begins.

12

Tiered CAPTCHA Resolution + CapSolver Integration

After deploying the propertytaxpayments.net handler for 191 counties, Cloudflare challenges began blocking searches. Built a 3-tier CAPTCHA resolution system where paid API is strictly last resort — preserving CapSolver credits for genuine failures only.

Tier 1 — Free (captchaDetector.js)

JS Challenge: Wait up to 25s polling every 2.5s — real Chromium auto-passes. Turnstile: Wait 6s (managed auto-approve) + try clicking iframe checkbox. Cost: $0 always.

Tier 2 — CapSolver (captchaSolver.js)

Only triggered if Tier-1 failed AND CAPSOLVER_API_KEY set AND type is Cloudflare. AntiTurnstileTaskProxyLess task via Node https. Polls every 3s, max 120s. Token injected into page then form submitted.

Blocked — No Solve

reCAPTCHA / hCaptcha / generic challenges return captchaBlocked immediately. No CapSolver credits spent on unsolvable types. Balance: GET /api/tax/capsolver/balance.

TX County Dual-Search Architecture
Sequential CAD → Tax Office search for all 254 Texas counties — two databases, one automated workflow
Why dual-search? Texas separates property appraisal (CAD = County Appraisal District) from tax collection (Tax Office). The CAD holds owner records and assessed values; the Tax Office holds tax bills and payment history. These are separate websites on separate platforms — both must be queried to get a complete property picture.

Phase 1 — CAD Search

Playwright navigates to the CAD URL using an existing handler (qpublic/tyler/beacon/ptaxpro/publicportal). Extracts owner information and the CAD account number.

qpublic.js tyler.js beacon.js ptaxpro.js publicportal.js
extractTaxAccountId() priority chain:
1. additionalDetails.taxOfficeRef
2. additionalDetails.refId / geoId / propId
3. Common key patterns (acctNum, parcelId…)
4. Top-level parcelId (last resort)

Phase 2 — Tax Office Search

Uses cadAccountNumber + cadOwnerLastName from Phase 1. Routes to the Tax Office handler matching the county's taxPlatform. Runs 4-strategy search on actweb.

propertytaxpayments (191) actweb (17) txcountytax (9) taxweb (4) go2gov (2) andersontax (1)
actweb 4-strategy search:
1. CAD Reference (cadref) — TX parcel ID = CAD ref
2. Account No. (account) with account number
3. Full cleaned owner name
4. Last name only (first word)

CAPTCHA & Bot Detection — Tiered Resolution
V3.0: Free Tier-1 self-solve first; paid CapSolver (Tier-2) only as absolute last resort. reCAPTCHA / hCaptcha are not attempted and return captchaBlocked immediately.

Tier 1 — Free Self-Solve (captchaDetector.js)

JS Challenge: Real Chromium auto-passes Cloudflare 5-second JS challenge. Wait up to 25s polling every 2.5s. Cost: $0.

Turnstile: Wait 6s (managed Turnstile auto-approves). If pending: find challenges.cloudflare.com iframe, click checkbox. Wait 4s. Cost: $0.

Tier 2 — CapSolver (captchaSolver.js)

Only if: Tier-1 failed AND CAPSOLVER_API_KEY set AND type is Cloudflare. Task: AntiTurnstileTaskProxyLess via REST API. Polls every 3s, max 120s. Token injected then form submitted. Balance: GET /api/tax/capsolver/balance.

Blocked — No Solve Attempted

reCAPTCHA, hCaptcha, and generic CAPTCHA challenges return captchaBlocked immediately. No CapSolver credits spent on types that CapSolver cannot solve.

Country IP Validation (8.1)

Many counties restrict access to US IP addresses only. Solution: deploy server in US-region. Eliminates IP-block retries that waste iterations. Cross-county concurrency further reduces detection probability.

Cloudflare Bot Detection (8.2)

Human/Bot detection via Cloudflare Turnstile, WAF rules, and behavioral analysis. Solution: Playwright-extra + puppeteer-extra-plugin-stealth. Spoofs WebGL, navigator.webdriver, canvas fingerprint, and other bot signals.

CAPTCHA Types (8.3)

reCAPTCHA v2/v3, hCaptcha, Cloudflare Turnstile, custom image CAPTCHAs. detectCaptcha() scans for telltale selectors. On detection: returns captchaBlocked result (422) with amber warning card. CAPTCHA results are NOT cached.

Concurrency CAP (8.4)

NetronOnline and county sites throttle concurrent sessions. MAX_CONCURRENT = 5 browser processes. Requests beyond this cap receive 503 Server Busy. activeSearches counter managed by server.js with increment/decrement lifecycle.

Search Timings (8.5)

Per-search timeout: SEARCH_TIMEOUT_MS=180000 (3 min) — 504 on expiry. Angular SPA timing: waitForAngularContent() polling. Frameset architecture: frame navigation delays. ASP.NET UpdatePanel postback: intercept XHR instead of waitForNavigation.

SSL & Sessions (8.6)

Self-signed certificate support via --ignore-certificate-errors. Tyler sIndex session handling hardened. Disclaimer/Terms modal auto-dismissal. ValidateUser.aspx session pre-step for qPublic. County-specific cookie/session management.

Important: CAPTCHA-blocked results are explicitly NOT stored in the LRU search cache. CAPTCHA is transient — a retry minutes later may succeed. Error/timeout results are also not cached. Only successful property record results are cached.
