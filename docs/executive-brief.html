What We Built

Opus One is a production-deployed microservice that replaces manual staff lookup of county government portals with fully automated AI browser agents. It navigates any US county property portal, extracts structured title and tax data, and returns results in seconds — at scale, with full observability and zero manual deployment steps.

🏢
Enterprise Architecture & Scalability
⬆ Vertical Scaling

The application is containerized and resource-configurable. Simply upgrade the EC2 instance type to increase CPU and memory — no code changes, no redeployment complexity. Handles increased Playwright concurrency automatically.

↔ Horizontal Scaling

Every component is stateless and Docker-native. Additional instances can be provisioned behind a load balancer at any time — whether on EC2, ECS, or Kubernetes — without application changes. Scales to any order volume.

🐳 Fully Containerized

The application, monitoring agent, and infrastructure metrics collector all run as Docker containers. Identical behaviour across development, staging, and production. Zero environment-specific configuration drift.

The platform is architected from day one to grow with the business — whether that means 10× order volume on the same server, or distributing across a cluster with a load balancer. The containerized foundation makes either path straightforward.

⚙️
Core Platform Capabilities
🤖 Multi-Agent AI Architecture

8 specialised AI agents — each built for a specific county portal platform (Tyler Technologies, Vision Government, Beacon, QPublic, BIS, Patriot, PublicPortal, Anderson Tax). Platform auto-detected per county, correct agent dispatched automatically.

🔍 Nationwide County Coverage

Supports county portals across all 50 US states. Built-in county URL directory with live health checks — dead URLs are auto-refreshed from public registry, never blocking an order silently.

⚡ Smart Result Caching

Search results cached for 4 hours. Repeat searches on the same property return instantly with zero browser overhead — dramatically reducing cost and latency under high order volume.

🔀 Dual-Source Parallel Search

For supported counties, the platform simultaneously queries both the Appraisal (CAD) and Tax Office databases in parallel, returning a single consolidated result — two data sources in one request.

🐳 Fully Containerized Platform

Every service — app, monitoring agent, metrics collector — runs as a Docker container. Consistent behaviour across all environments. Deploy to any cloud or on-premise host with a single command. Foundation for horizontal and vertical scaling.

🛡️ Concurrency Management

Manages up to 3 simultaneous browser sessions with built-in queue protection. Requests beyond capacity return a clean busy-state response rather than crashing or silently timing out.

⚠️ CAPTCHA Detection & Flagging

CAPTCHA-blocked searches are detected, logged, and surfaced with clear order-level notes for manual follow-up — no silent failures, no lost orders.
